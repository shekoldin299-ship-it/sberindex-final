# V3: самостоятельное расширение исследования

Протокол фиксируется до новых расчётов 8 октября 2026 года. V1/V2 и их результаты сохраняются.

## Прогноз
Существующий набор, категории и шкала неизменны. Основные origins: 18, 21, 23; горизонты 1/3/6 при наличии факта. h12 — единственный диагностический origin 12, правило V2 сохраняется без подбора.

Новые кандидаты собственной реализации: медианная общая динамика логарифмов категории и местное отклонение от неё. Общая сезонная траектория переносится с прошлого года с медианным годовым ростом последних 3 или 6 месяцев. Локальный уровень — последние 3 месяца отклонений. Смеси с местным сезонным прогнозом: 25%, 75% общего компонента. Ещё два кандидата — равные смеси каждого такого прогноза (75%) с V2. Медиана рассчитывается исключительно по истории до origin; это общий фактор панели, не официальный национальный индекс.

Выбор по MAE отдельно для категории/горизонта на прежних 50 tuning-МО V2. Замена V2 требует минимум 2% улучшения. После сохранения политики она не меняется по новой оценке. Новые кандидаты опубликованы полностью, включая проигравшие. Финальная оценка — все доступные пары; отдельно 50 tuning, 100 calibration, 100 V2-test, 10 pilot и остальные территории. Группа remaining не является независимым временным тестом: календарь прежний, простые baseline ранее рассчитаны по всей панели. Не заявляется spatial cold-start: прошлое оцениваемых МО доступно общему фактору.

Prophet не пересчитывается по всей панели: существующие проверенные парные прогнозы V2 используются на тех же ключах. Нельзя сравнивать его MAE на выборке с MAE других методов по всей панели. Отдельные таблицы по категориям, включая «Все категории». Интервалы V2 не переносятся на V3 без перекалибровки; для выбранного V3 используются прежние 100 calibration-МО, с явным указанием ретроспективности.

## Детектирование
Полусинтетическая проверка на реальных рядах «Все категории», имеющих полную историю. МО делятся по SHA256(seed=20261011): первые 300 калибровка, следующие 300 тест. Для каждого ряда: контроль, одиночный выброс, постоянное повышение/понижение уровня на 10%/20%, изменение наклона; начало 15..19 по независимым seed 20261012/20261013. Возмущения вносятся в отдельный ряд при неизменной контрольной панели. Это приближение редкого локального события, не общероссийского кризиса. Контрольные ряды могут содержать неизвестные реальные события, поэтому тревоги на них не обязательно экономически ложные.

Сравнение прежних CUSUM/V2 и новой последовательной статистики отклонения годового роста от медианного роста панели. Нормировка по межмуниципальному MAD текущего месяца (нижняя граница 0.02), окна 1/2/3, пороги 2/3/4/5/6/8, cooldown 3. Порог каждого семейства выбирается только на calibration при доле контрольных рядов с тревогой <=5%, максимизируя F1, иначе минимум тревог. Тест неизменен. Окно совпадения 0..2 месяца, ранние и повторные тревоги — FP; одиночные выбросы не считаются структурным изменением. Показываются TP/FP/FN, precision/recall/F1, контрольные тревоги и задержка, включая пропуски. Новая статистика обнаруживает уже наблюдаемое изменение, не предсказывает событие заранее.

Ряды без единого наблюдения до origin исключаются из этой даты для всех моделей одинаково; последующие наблюдения для заполнения не используются. Число исключений публикуется. Пропуски внутри наблюдаемого префикса обрабатываются прежней процедурой V2.

## Границы
Разработка ретроспективная на известной истории. Реализация самостоятельная; общие математические идеи не заявляются как изобретение. Основная публикация должна различать результаты baseline V2, выбранного V3 и экспериментальных кандидатов. Преимущество оценивается только на сопоставимых выборках.
