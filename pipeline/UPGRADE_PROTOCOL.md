# Протокол усиления V2 — до новых расчётов

Исходная версия: GitHub 3edab341d241289a8fa3695a8cb3d2a6a3a9cbd2. Её результаты не заменяются.

Это ретроспективная разработка после просмотра V1. Новых календарных периодов нет. Первые 50 МО используются для выбора модели по категории/горизонту. Следующие 100 МО V1 — только для масштаба интервалов. Новая выборка 100 МО с seed=20261010 исключает все предыдущие 160 МО и определяется по покрытию первого года. Не менять политику по результатам новой выборки. Географическая проверка не является независимой временной проверкой; исторические данные оцениваемых МО могут входить в pooled-обучение до origin.

Кандидаты: сезонность с ростом, прежняя Ridge, их смеси с весами Ridge 0/0.25/0.5/0.75/1; Chronos с предварительным удалением сезонного профиля и восстановлением прогноза; смесь 25% адаптированного Chronos и 75% сезонной модели. При выборе по MAE на 50 МО переход от сезонной модели разрешён только при улучшении минимум 2%. h=12 не подбирается: прежний затухающий тренд. Короткая история (<18 месяцев) — сезонная модель. Chronos остаётся zero-shot, веса и ревизия V1; адаптация входа не называется дообучением.

Профиль сезонности Chronos: первый год, из log1p удаляется линейный наклон, профиль центрируется; деление ряда на exp(профиль), восстановление после прогноза. Используются только данные префикса. Предел результата 0.25–4 последнего значения.

Интервалы: уровень 90%, по каждой категории и горизонту. На калибровочных МО взять максимум относительной абсолютной ошибки по origins внутри МО; нормировщик — среднее доступного префикса. Квантиль порядка ceil((n+1)*0.9), нижняя граница неотрицательна. Проверить точечное и совместное по МО покрытие, ширину. Это conformal-inspired калибровка по территориям: обменность и независимость календаря не доказаны; временная гарантия 90% не заявляется. Для прогнозов из декабря 2024 шкала переносится с других origins условно.

Детекторы: прежний CUSUM-8 против медианного окна из 3 остатков и многомасштабной суммы ограниченных остатков (окна 2–6). Для новых методов остатки V1, обрезка ±3, cooldown 6. Пороги 2/3/4/5/6/8. Независимые синтетические seeds: калибровка 2042, тест 3042, по 100 каждого типа, длины 24/60. Выбор по среднему F1 обеих длин при null alarm <=10% для каждой длины; если нет допустимых, минимум максимальной null-rate, затем F1. Один метод фиксируется до теста. Baseline измеряется на тех же случаях. Сигналы только после наблюдения, не прогноз будущего шока.

В демо показывать фактические результаты, качество исходных данных, интервалы с оговорками и известные на момент сигнала новости. Полные новости V1 сохраняются; новые неподтверждённые причинные связи не добавляются.
