# Прогноз потребления и мониторинг изменений

**Щеколдин Ярослав Данилович** · СберИндекс · номинация «Прогнозирование»

Решение прогнозирует средние безналичные расходы жителя муниципалитета по шести
категориям и выявляет локальные изменения после получения новых наблюдений.
Данные: 2 190 муниципалитетов, январь 2023 — декабрь 2024.

Основной репозиторий проекта для сдачи на конкурс. Актуальная модель — **V5**.
Код, данные, конфигурация, результаты, отчёт и презентация находятся в этом репозитории.

## Результаты

Сравнение V5 с предыдущей V4 на одинаковых парах прогноз–факт:

| Горизонт | MAE V4, руб. | MAE V5, руб. | Дат выпуска |
|---|---:|---:|---:|
| 1 месяц | 371,44 | 307,85 | 12 |
| 3 месяца | 393,73 | 393,73 | 2 |
| 6 месяцев | 446,59 | 446,59 | 1 |
| 12 месяцев | 784,32 | 650,41 | 1 |

Месячная MAE снизилась на 17,1%, выигрыш получен во всех шести категориях и в 9 из
12 месяцев. Детектор confirmed2: F1 0,605, precision 0,791, recall 0,489 на отдельной
полусинтетической проверке 300 муниципалитетов. Это не доказательство предсказания
кризиса до появления наблюдений.

Годовой компонент дополнительно проверен ровно на 12 месяцев вперёд на десяти датах,
с 3–12 месяцами муниципальной истории. MAE по шести категориям — 761,46 руб.,
у простой модели национального роста — 684,14 руб. Результат на одной дате
не следует переносить на весь год. Построчные данные и ограничения раскрыты в отчёте.

V5 выбрана после исследования истории 2024 года. Независимого будущего теста нет.
Национальный ряд взят из текущей версии выгрузки; фактические исторические версии
публикаций не восстановлены. Проверены предположения задержки данных 1 и 2 месяца.
Интервалы V5 ещё не откалиброваны. Экспорт на 2025 год получен из декабря 2024,
он является историческим примером, а не прогнозом на дату подачи.

## Запуск

Проверенная среда: Linux x86_64, Python 3.12, CPU.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install torch==2.6.0+cpu --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt
python run.py check
```

Проверка работает без сети и обучения: контрольные суммы, 54 unit-теста, сверка
метрик, фактических целей, подписей исходников и годовой проверки на 10 датах.

Пересчёт слоя V5 из сохранённой базы V4, без сети:

```bash
python run.py v5 --output ../sberindex-v5-recomputed
python research/v5/export.py --output ../forecast-v5.csv.gz
```

Гиперпараметры V5 читаются из `research/v5/config.json`. Для своей конфигурации:
`python run.py v5 --config my-config.json --output ../my-v5-run`.
Доступны окна оценки роста и уровня (1–12 месяцев), ограничения темпа роста
и вес общего темпа (0–1). Запуск сохраняет `effective_config.json` рядом с результатами.
Стандартная конфигурация воспроизводит опубликованные прогнозы. Изменённая
конфигурация — новый эксперимент, к которому опубликованные метрики не относятся.
Таблица сравнения с Prophet в отчёте относится к V3, таблица V5 — к сравнению с V4.

Каталог/файл вывода должны быть новыми. Исходные доказательства не перезаписываются.
Полное обучение исходного конвейера V3: `python run.py reproduce --output ../sberindex-recomputed`.
Оно может занять часы и при первой загрузке весов требует сети. Порядок расширения
V4: [инструкция](research/v4/README.md). Затем выполняется слой V5 указанной выше командой.
Сборка PDF отчёта: `python run.py report`.
