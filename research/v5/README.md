| 12 месяцев | 784,32 | 650,41 | 1 |

## Модель

Для h=1 берётся равновесная смесь V4, сезонного панельного прогноза с последним
общим темпом и локальной сезонной смеси. Для h=12 используется медианное отношение
муниципальных расходов к национальному ориентиру за последние три месяца.
Для h=3/6 V4 сохраняется точно. Формулы реализованы в model.py.
Национальный ориентир использует сезонный аналог и медиану последних трёх годовых
логарифмических темпов. Основной лаг доступности составляет 1 месяц, чувствительность 2.
Национальные и муниципальные префиксы отсекаются до расчёта любых признаков.
Заполнение неполной истории V5: ffill, затем bfill внутри доступного префикса.

## Проверка и воспроизведение

Из корня: python run.py check. Пересчёт: python run.py v5 --output ../new-v5.
Команда воспроизводит слой V5 из замороженных прогнозов V4, не обучает заново V3/V4.
Экспорт: python research/v5/export.py --output ../forecast-v5.csv.gz.
Экспорт использует исходный V3, воспроизводит месячную коррекцию V4 и добавляет V5.

metrics.csv: 200 352 пары для четырёх горизонтов, 150 228 месячных пар.
by_month_category.csv: результаты всех дат и категорий, включая проигрыши.
verify.py сверяет факты с исходными данными, ключи, подписи и метрики.
test_model.py: шесть тестов, включая инвариантность к будущему и задержке данных.
Отклонённые кандидаты и их метрики сохранены в архиве, коммит 6f98ffca.

## Ограничения

Выбор формулы сделан после исследования этой истории. Нет независимой оценки
будущего, ранга во всём конкурсе или доказательства причин событий. Для годового
горизонта одна дата. Новые интервалы требуют отдельной калибровки.
Источник и лицензия данных: SOURCES.json. Национальный показатель и муниципальные
категории отличаются по составу. Текущая выгрузка не воспроизводит архив публикаций.
