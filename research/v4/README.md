# Расширенная проверка прогноза и мониторинга

Щеколдин Ярослав Данилович. Результаты от 9 октября 2026 года.

## Что улучшено

На всех 12 доступных месячных датах выпуска защитная смесь снизила MAE месячного
прогноза с 383,62 до 371,44 руб. (3,17%, 150 228 пар). На новой группе из 300 МО
детектор confirmed2 достиг F1 0,605 против 0,416 у прежнего консервативного режима.
Предупреждение о будущем событии до наблюдения не доказано.

| Проверка | Прежний вариант | Новый вариант |
|---|---:|---:|
| Месячный прогноз, MAE по 12 датам, руб. | 383,62 | 371,44 |
| Детектор, F1 на дополнительных 300 МО | 0,416 | 0,605 |
| Детектор, полнота | 27,1% | 48,9% |
| Детектор, precision | 89,8% | 79,1% |
| Контрольные ряды с тревогой | 1,0% | 1,67% |
| Медианная задержка среди обнаруженных изменений | 2 месяца | 1 месяц |

Улучшение детекции повышает чувствительность ценой части точности тревог. Новое
правило выбирается по калибровочным территориям. Подтверждающие территории не
используются для изменения порога. Фон содержит наблюдаемый фактор текущего
месяца, а искусственное изменение вносится в один ряд.

## Как устроен новый прогноз

Модели разлагают логарифм расходов на общий фактор категории и местное отклонение.
Проверены усадка годового роста, продолжение местного уровня, затухание и бустинг
остатка. Веса online_mix используют только уже наблюдавшиеся цели. Защитное
правило safe_mix оставляет V3, пока три последние известные месячные ошибки новой
смеси не окажутся хотя бы на 2% ниже. Тогда используется равная смесь двух
прогнозов. Правило работает отдельно по категориям.

Это вторая итерация дизайна после просмотра первого эксперимента. Сам V3 ранее
выбран на известной истории. Поэтому численное преимущество описывает
ретроспективный эксперимент и не является независимым будущим тестом. Диагностический
bootstrap по 12 датам даёт интервал разницы MAE [-18,53; -6,15] руб., но месяцы
зависимы, а период короткий.

## Какие варианты не приняты

Первый online_mix выигрывал 4,9% на трёх прежних датах, но на полном календаре
проиграл V3: 426,85 против 383,62 руб. Его прямое применение отвергнуто.
Новые прогнозы на 3/6/12 месяцев проиграли прежней системе. Дополнительно
пересчитаны сырой и сезонно адаптированный Chronos-Bolt-Tiny. На годовом горизонте
MAE составила 3255,13 и 1887,43 против 784,32 у V3. Эти режимы не приняты.
Все результаты сохраняются, включая отрицательные.

## Как проверить

Из корня репозитория с установленными основными зависимостями:

```bash
python -m unittest discover -s research/v4 -p 'test_*.py' -v
python research/v4/verify.py
```

Полный пересчёт в новые каталоги:

```bash
python research/v4/run.py --output /tmp/sber-v4-forecast
python research/v4/expand_baseline.py /tmp/sber-v4-forecast /tmp/sber-v4-expanded
python research/v4/safe_update.py /tmp/sber-v4-expanded /tmp/sber-v4-safe
python research/v4/detectors.py /tmp/sber-v4-detectors
python research/v4/confirm_detector.py /tmp/sber-v4-confirmation
```

Первая загрузка закреплённых весов Chronos требует сети. Вычисления работают на CPU.
Сохранённые файлы не перезаписываются. Результаты V3 находятся в
`pipeline/v3_results`, новые эксперименты в `research/v4/results`.

Данные — набор СберИндекса. Описание источников и лицензий находится
в корневом SOURCES.md.

Крупные таблицы сохранены как каталоги Parquet с частями `part-*.parquet`.
`pandas.read_parquet` читает каждый такой каталог как одну таблицу.
Проверено точное совпадение всех строк и значений с исходными файлами.

Для повторного эксперимента Chronos сохранена итоговая metrics.csv. Его построчные выгрузки в комплект не включены; эта сводка не заменяет проверку отдельных прогнозов.
